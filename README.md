# Soldados-de-Vidal

Programa: Servidor

Autores: Bautista Hurtado Lázaro, Castro Franco José Emiliano, Pérez Flores Miguel Ángel


La aplicación desarrollada en este proyecto consiste en un servicio de mensajería donde tú y otros usuarios conectados al mismo servidor pueden charlar entre si, ya sea por mensaje directo, grupal, general o a través de un canal de difusión. Contarán con identificadores como nombre de usuario y foto de perfil seleccionable al iniciar sesión.

El sistema es compatible y se puede ejecutar en **Windows, Linux y macOS**. Solo necesitas tener instalado:
- Python 3.8 o superior.
- Paquete gráfico de Python para Tkinter.


Para conectarte, sigue los siguientes pasos:

1. Guarda en un archivo .py el módulo del programa: **cliente**
2. Descarga la carpeta con los avatares.
3. Crea una carpeta donde se encuentres los dos archivos que descargaste.
4. En la terminal del equipo, ubicado en el directorio donde guardaste los dos archivos, ejecuta el siguiente script: "python3 cliente.py"
5. Una vez dentro, piensa bien en un usuario y contraseña que recuerdes. Introdúcelos en los campos solicitados y haz clic en "Registrarse".
6. Una vez registrado, con las mismas credenciales introducidas en los mismos dos campos, haz clic en "Iniciar sesión".
7. Procede a seleccionar tu ávatar en la sección de avatares que verás a continuación y entra.
8. ¡Socializa!
